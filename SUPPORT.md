# Dukungan

Butuh bantuan dengan **ILUNI FT ELEKTRO UNPAK WebApps**? Berikut saluran yang tersedia:

## Saluran Dukungan

| Kebutuhan | Saluran |
|---|---|
| Bug / masalah teknis | [GitHub Issues](https://github.com/ilunifteunpakinfra-spec/webapps/issues) — gunakan template *Bug Report* |
| Permintaan fitur | [GitHub Issues](https://github.com/ilunifteunpakinfra-spec/webapps/issues) — gunakan template *Feature Request* |
| Panduan penggunaan aplikasi | [User Manual](https://ilunifteunpakinfra-spec.github.io/webapps/) (VitePress + PDF) |
| Masalah keamanan | [SECURITY.md](SECURITY.md) — jangan buat issue publik |
| Kontak pengelola | `iluni.fte.unpak@gmail.com` |

## Sebelum Membuat Issue

1. Cari di [Issues](https://github.com/ilunifteunpakinfra-spec/webapps/issues) apakah masalah sudah dilaporkan.
2. Baca [User Manual](https://ilunifteunpakinfra-spec.github.io/webapps/) — mungkin jawabannya sudah ada di sana.
3. Sertakan informasi yang cukup: langkah reproduksi, hasil yang diharapkan vs aktual, screenshot, dan versi browser.
