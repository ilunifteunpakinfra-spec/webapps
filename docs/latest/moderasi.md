# Melaporkan Konten

## Pendahuluan

Setiap pengguna dapat **melaporkan konten** yang dianggap melanggar aturan komunitas. Laporan diteruskan ke admin untuk ditinjau dan ditindaklanjuti. Modul ini menjelaskan jenis konten yang dapat dilaporkan dan cara melaporkannya.

## Konten yang Dapat Dilaporkan

Berikut jenis konten yang memiliki tombol **Laporkan**:

| Jenis Konten | Contoh Pelanggaran |
| --- | --- |
| **Lowongan** | Lowongan palsu atau menyesatkan. |
| **Pengumuman** | Informasi tidak pantas atau tidak relevan. |
| **Polling** | Pertanyaan yang provokatif atau menyinggung. |
| **Grup** | Grup dengan konten atau tujuan melanggar aturan. |
| **Galeri** | Foto yang tidak pantas atau melanggar privasi. |
| **Profil** | Profil dengan informasi palsu atau menyesatkan. |

## Melaporkan Konten

### Langkah-langkah

1. Buka halaman konten yang ingin dilaporkan (misalnya detail lowongan atau profil).
2. Klik tombol **Laporkan** pada konten tersebut.
3. Pilih atau tuliskan **alasan pelaporan**.
4. Klik **Kirim Laporan**.

### Setelah Melaporkan

- Laporan diteruskan ke admin untuk ditinjau.
- Status laporan dapat dipantau oleh admin pada panel **Moderasi Konten**.
- Pengguna yang melaporkan tidak dapat melihat identitas satu sama lain secara publik.

## Batasan Pelaporan

- Berikan laporan **berdasarkan fakta** dan alasan yang jelas.
- Jangan menyalahgunakan fitur laporan (misalnya melaporkan konten yang sebenarnya tidak melanggar).
- Penyalahgunaan berulang dapat dikenakan sanksi oleh admin.

## Apa yang Terjadi Setelah Laporan?

1. Admin menerima laporan pada panel moderasi.
2. Admin meninjau konten yang dilaporkan.
3. Admin dapat **menyelesaikan** laporan (konten dianggap aman) atau **menindaklanjuti** (misalnya menghapus konten atau menonaktifkan pengguna).

Lanjutkan ke [Panduan Admin](/latest/admin/) untuk memahami tugas pengelola.
